# cli-ai-chatbot · 命令行 AI 聊天机器人

基于 DeepSeek API 的命令行流式多轮对话工具，内置**错误重试、token 成本核算与上下文管理**。
纯 Python 标准库 + OpenAI 兼容 SDK，无其他框架依赖。

> 这是作者「16 周 AI 应用开发学习路线」第 2 周的综合作品，定位是后续 RAG / Agent 项目的工程地基。

## 功能

- **流式输出**：逐字打印，首字响应快，不等全文
- **多轮对话**：完整历史管理，失败自动回滚，不会留下"有问无答"的脏历史
- **智能重试**：错误三分类（可重试 / 致命 / 未知），指数退避 + 随机抖动；已开始输出的内容不重试
- **成本核算**：区分输入/输出、缓存命中/未命中，识别高峰与空闲时段（单价差 2 倍），每轮实时记账，支持月成本预估
- **上下文管理**：滑动窗口裁剪历史（system 永不裁、问答对不切开），配合前缀缓存降低单会话成本约 26%
- **自动存档**：每轮落盘，崩溃不丢对话；支持手动存档 / 读档

## 快速开始

```bash
# 1. 克隆并安装依赖
git clone https://github.com/<你的用户名>/cli-ai-chatbot.git
cd cli-ai-chatbot
python -m venv .venv
.venv\Scripts\activate        # Windows；macOS/Linux 用 source .venv/bin/activate
pip install -r requirements.txt

# 2. 配置密钥
copy .env.example .env        # 然后编辑 .env，填入你的 API Key

# 3. 运行
python chatbot.py             # 交互式聊天
python chatbot.py --selftest  # 本地逻辑自测（不联网、不花钱）
python chatbot.py --demo      # 单轮验证接口连通性
```

API Key 在 [DeepSeek 开放平台](https://platform.deepseek.com) 申请，充值 10 元即可支撑数千次对话。

## 使用命令

| 命令 | 作用 |
|---|---|
| `/cost` | 账本：调用次数、单次均价、累计费用、月成本预估 |
| `/clear` | 清空对话历史（system 保留，账本不清零） |
| `/history` | 查看当前历史条数 |
| `/save` / `/load` | 手动存档 / 读档（每轮成功后也会自动存档） |
| `/quit` | 退出，自动存档并打印账单 |

## 设计要点

**1. 流式响应中主动获取用量**
流式模式下服务端默认不返回 token 用量，需显式传 `stream_options={"include_usage": True}`；且携带用量的末帧 `choices` 为空列表，必须先取 usage 再判空，否则会在输出完成后抛 `IndexError`。用量缺失时按字符数估算兜底，并在界面明确标注"估算值"——计费场景不使用估算数。

**2. 流式重试的副作用控制**
普通请求失败可直接重试；流式一旦开始打印，已显示的内容无法撤回，重试会导致输出拼接错乱。因此用状态标记区分：未打印 → 走指数退避重试；已打印 → 立即失败并回滚历史，本轮不计入。

**3. 成本结构分析与降本**
多轮对话全量重发历史导致成本近似平方增长。通过滑动窗口裁剪 + 稳定前缀可缓存，单会话成本由 0.0228 元降至约 0.0169 元（**降 26%**）。裁剪实现保证 system 提示永不丢弃、问-答对不分离。实测同一调用在高峰时段（工作日 9–12 / 14–18 点）成本为空闲时段的 2 倍，批量任务应错峰调度。
